Task 1.1 – Find the Problems

1. Lines 15–18: open() calls
Problem: The program does not check whether the files opened successfully.
Effect: The program may use an invalid file descriptor.
Correction: Check whether each file descriptor is less than zero and report errors using perror().

2. Line 17: Missing O_TRUNC
Problem: The output file is not cleared if it already exists.
Effect: Old data may remain at the end of the output file.
Correction: Add O_TRUNC when opening the output file.

3. Line 23: printf("%s", buffer)
Problem: The buffer is not guaranteed to contain a null-terminated string.
Effect: The program may read beyond the buffer or display incorrect data.
Correction: Use the number of bytes returned by read() instead of treating the data as a string.

4. Lines 24–26: write(..., BUFFER_SIZE)
Problem: The program always writes 64 bytes instead of the number actually read.
Effect: Extra or invalid bytes may be written.
Correction: Write only bytes_read bytes.

5. Lines 24–26: Ignoring the return value of write()
Problem: The program does not check whether all requested bytes were written.
Effect: Data may be missing from the output file.
Correction: Check the return value and loop until all bytes are written.

6. Line 20: Handling read() errors
Problem: The program does not report errors when read() returns a negative value.
Effect: The copy may stop without reporting the failure.
Correction: Check whether bytes_read is less than zero and report the error.

7. Lines 29–30: close() calls
Problem: The program does not check whether closing the files succeeds.
Effect: File-related errors may go unnoticed.
Correction: Check the return value of each close() call.
